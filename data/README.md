# Data

This project uses **no external datasets**. All results come from simulated random numbers generated by the code in `notebook/` and `docs/`.

| File | Description | Source (with link) | Licence | Date accessed |
|---|---|---|---|---|
| none | The only inputs are the model parameters: arrival rate 6 cars/min and service rate 2.5 cars/min per booth (peak-time example values, not measurements) | set at the top of the notebook | n/a | n/a |

To apply the model to a real toll plaza, replace the two example rates with values estimated from counted arrivals and timed services, recording counts as aggregates only (no personal data), and list the source and licence in the table above.
