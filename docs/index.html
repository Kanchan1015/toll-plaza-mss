Toll Plaza Queue Simulation

How many toll booths must be open at peak time to keep the average wait under two minutes? Change the traffic and the booths, and watch the queue.

About / How to use

This is a live simulation of cars at an expressway toll plaza. Cars arrive at random (average λ per minute) and join one first-come-first-served line. Each open booth serves one car at a time, taking a random time with average 1/μ minutes. The program counts how long every car waits in line (before service starts).

  • Set λ, μ and the number of booths, then press Start. Pause stops the run; Reset clears it. Changing a setting resets the run.
  • Run to end skips the animation and simulates all the cars so you can read the final answer straight away.
  • Car colour shows waiting time: blue under 1 min, amber 1–2 min, red over 2 min.
  • ρ = λ / (cμ) is the traffic intensity. If ρ ≥ 1 the booths cannot keep up and the line grows without limit.
  • The mean wait is shown with a 95% confidence interval (batch means, after a warm-up) and is compared with the exact Erlang C formula.
